# xfce4-minios-tasklist-plugin

MiniOS fork of Xfce Window Buttons for Xfce 4.20.

It adds pinned applications, pin/unpin actions, drag-and-drop pinning and reordering, pinned-app management in settings, optional expansion across free panel space, and removes the grouped-window number badge. Visual styling is provided by the Greybird-MiniOS GTK theme.
